# Security policy

## Scope

Opatchy is an unsandboxed plugin loaded by `omarchy-shell`. The future runtime
is intended to present update and advisory information and open native update
workflows; it is not a privilege boundary and does not perform package
mutation.

## Reporting a vulnerability

Until the public repository is available, report suspected repository or
design issues privately to the maintainer associated with
https://github.com/tomge/opatchy. Include a minimal reproduction, affected
revision, impact, and any required environment details. Do not include tokens,
private package inventories, or other sensitive data unless necessary for the
reproduction.

## Limitations

No release or runtime exists at this repository-contract stage. Later security
features must describe advisory matching, available fixes, CISA KEV listing,
and stale or unavailable evidence precisely; they must not claim that a system
cannot be exploited or is fully protected.
